Check-in Status Logic

Status is never stored as a static enum. It is derived at read time by comparing the sum of seats in checkInHistory against booking.seats:

const totalCheckedIn = booking.checkInHistory
  .reduce((sum, entry) => sum + (entry.seats || 0), 0)

booking.checkinStatus = totalCheckedIn >= booking.seats
// true  → fully boarded (all seats)
// false → available or partially boarded
