🟢 Entirely New Features (No Equivalent in Old System)

/marketing
Marketing Dashboard
Booking overview stats, LINE campaign performance, top booking segments, GA4 user journey analytics — all filtered by event
/bookings/requests
Booking Requests Queue
Unified queue for Draft bookings + Pre-booking requests. Admin approves/rejects; on approval LINE deep-link sent to customer automatically
/bookings/multi-export
Multi Event Export
Export booking data across multiple events in a single XLSX file
/bookings/payment-recovery
Payment Recovery
Manual payment recovery tool for failed KBank QR payments; full audit trail at /history and /history/[id]
/bookings/daily-reconciliation/history
Daily Reconciliation
Automated KBank daily reconciliation: mismatch detection, run history list, and per-run detail with mismatch breakdown
/payments
Payments Overview
KBank QR payment dashboard with summary stats and status breakdown
/payments/transactions
Transaction List & Detail
Browse all payment transactions with filters; per-transaction detail with callback timeline at /transactions/[id]
/payments/alerts
Payment Alerts
Reconciliation mismatch alerts and alert recipient management
/settings/feature-flags
Feature Flags
Toggle features on/off at runtime without re-deploying the application
/otp-logs
OTP Audit Logs
View all OTP events (sent / verified / expired) per phone number or booking for auditing and support
/events/bookings
Event Bookings View
Browse all bookings scoped to a specific event — filterable by route, round, and status
Summary: Old system had 11 pages (some with up to 3 stacked functions per page), all under a single /event/… namespace, with no type safety, no payment features, and no analytics.

New system has 30+ pages / routes across 6 sections. Every multi-function old page has been split into dedicated pages with their own URL, so admins can bookmark and navigate directly. Major new capabilities added:
  • Full Payments module — KBank QR overview, transaction detail, alerts
  • Marketing Dashboard — LINE campaign analytics + GA4 user journey funnel
  • Daily KBank reconciliation with automated mismatch detection
  • Unified Booking Requests queue (Draft + Pre-booking approval flow)
  • Payment recovery with full audit trail
  • Feature flags for runtime control
  • OTP audit logs for customer support
  • Per-campaign LINE message history with detail view
