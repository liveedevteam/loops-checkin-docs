Key Components

components/checkin-modal.tsx

CheckInModal

Full-screen overlay managing 4 states: loading, success (with seat counter), error, and multiple-bookings list. Calls onConfirm(seats, passengerId).

components/qr-scanner.tsx

QRScanner

Wraps @zxing/library BrowserQRCodeReader to decode QR from live camera stream. Emits decoded string via onScan prop.

lib/indexedDB.ts

getDataFromIndexedDB

Opens or creates the "checkin" DB (v1). Reads a single record by key from the specified store. Returns the value and optionally calls a React setState setter.

lib/indexedDB.ts

updateDataInIndexedDB

Opens the "checkin" DB and put()s the entire updated object into the store using the object's own id field.

lib/patchDataToAPI.ts

patchDataToAPI

Takes a listticket queue and routeCode, POSTs { checkInCode, checkList } to NEXT_PUBLIC_API/bookings/adm/check-in. Returns { status, data }.

lib/qr-processor.ts

QRProcessor (singleton)

Singleton class. processPhoneNumber(phone, bookings) filters local booking array. checkInPassenger() handles seat accounting and API submission.

Background Sync Timer

Running on /main, /checkin, and /phone-checkin:

setInterval(async () => {
  if (listTicket && routeCode && listTicket.data.length > 0) {
    const result = await patchDataToAPI(listTicket, routeCode)
    if (result.status === true) {
      listTicket.data = []                    // clear queue
      updateDataInIndexedDB("listticket", …)
      // merge updated bookings into local state
      updateDataInIndexedDB("booking", …)
    }
  }
}, 5000) // every 5 seconds
